# NextJS Homework – CSCI 331

A simple React and NextJS application demonstrating components, props, state, and API integration.

## Features

- **Counter App:** Two counter instances using different increment values (+1 and +2), with custom button colors and a reset when the count exceeds 10.
- **GitHub Link:** A page describing my web development interests and final project idea.
- **Store:** A searchable product table that retrieves product information from the Fake Store API.
